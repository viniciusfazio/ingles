🤖 IA dentro do app

Com uma chave da API do Gemini, a correção da escrita, a conversa e a missão acontecem aqui dentro, sem sair do app. A chave fica guardada só neste celular (não entra no backup). Sem chave, as tarefas continuam indo pelo botão "Mandar".

Como conseguir a chave (quem cuida do curso faz isso, uma vez)
  1. Entre em aistudio.google.com com a sua conta Google.
  2. Menu Get API key → Create API key. Se pedir um projeto, crie um novo.
  3. Copie a chave (começa com AIza) e cole aqui em cima. Toque em Testar e salvar.

Recomendado: no Google Cloud, em APIs e serviços → Credenciais, restrinja a chave ao endereço deste site e à Generative Language API. Assim ela não serve para mais nada se alguém pegar o celular.
